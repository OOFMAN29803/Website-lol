AllOneLM

Architechure: PyTorch lightning.
Parameter count: 66 Million parameters.
Fine tuned?: No
Context window: 0 tokens (No context implemented)
Input amount: unlimited. (trained on sentence length 50 or 200)
Output amount: 50 tokens
Trained on: Yahoo answers CSV dataset
Filter: None (Although that isn't an issue because it is really bad at talking)
Hosted on: Hugging Face
